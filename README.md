## What I'm building

- **[mrbrunch.ch](https://mrbrunch.ch)** — enterprise e-commerce platform for a Swiss brunch delivery service. Stripe checkout, B2B company accounts, subscription orders, inventory-driven catalog, Bexio billing. Next.js 16 · Prisma · TypeScript · Vercel.
- **[briangantner.ch](https://briangantner.ch)** — portfolio and contact hub.
- **20+ Swiss client platforms** — physiotherapy, optometry, photography, jewelry, gardening, hairdressing, sewing studios. Bilingual (DE/EN), animated, deployed on Vercel.
- **AI-powered features** — Claude API, Vercel AI SDK, agentic workflows, MCP integrations on top of production apps.

## How I work

- **Clean Architecture** with ESLint-enforced boundaries — domain layer has zero external dependencies
- **Type-safe end-to-end** — Zod-validated APIs, Prisma typed queries, no `any`
- **Production-first** — observability, audit logging, sensitive-data masking, CSRF, rate limiting
- **Swiss quality, fast delivery** — ships under tight timelines without skipping the basics
